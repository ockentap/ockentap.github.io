aBulb

Android · Bluetooth Mesh

Control a Bluetooth-mesh bulb straight from the phone — no hub, no cloud, no account. The app joins the mesh as a proxy client and drives the standard Light Lightness model; it can provision a factory-fresh bulb on its own.

  • 2.5 MB to download, Android 8.0+
  • No network permission at all — nothing to phone home with
  • Pairs with real hardware, tested on a LEDVANCE Smart+ bulb

hermes-dynamic-memory

Python · AI agent infrastructure

A two-tier memory architecture for AI agents: a ~500-token keyword index in the system prompt, with verbose detail living in topic files on disk, routed by keyword.

  • Replaces a hard 2,200-character memory cap that silently truncates facts
  • Plugin-enforced integrity — the index can't drift from the files
  • Benchmarked honestly against stock memory, raw answers and failed runs published

How I build

The pattern behind the project list.
/ android

Native apps that stay small

Kotlin and Compose, sized against what the vendor app costs you in megabytes and permissions. If a feature needs a cloud, it should be a cloud the user already has.

/ radio

Protocols, not middlemen

Bluetooth LE and Bluetooth SIG Mesh at the GATT level: provisioning, proxy clients, vendor model quirks. The interesting bugs are always on the wire.

/ agents

AI-agent infrastructure

Memory architecture, context budgets, browser control and plugin-enforced invariants for agents that run unattended — plus benchmarks that survive scrutiny.

/ infra

Self-hosted, end to end

Linux servers, systemd units, Tailscale networks, containers and cron watchdogs. If it matters, it runs on hardware I control.

/ tooling

Automation with taste

Python for the things worth automating, terminal UIs for the things worth using twice, and no service dependency where a script will do.

About

I'm ockentap — a developer who builds for the gap between what software could be and what the vendor shipped.

The through-line across everything here is removing a layer that didn't need to exist: the hub between the phone and the bulb, the vendor app between you and your own air conditioner, the gallery between you and one photo, the 2,200-character cap between an agent and what it knows.

I'd rather ship something small that works on real hardware — a real bulb, a real air conditioner, a real server — than something large that works in a demo.
